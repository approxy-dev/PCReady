Everything About Running PCReady

Getting started

Install PCReady, let it scan the system, then pick a profile or individual applications.

Working with profiles

Profiles bundle applications per role. Install missing only skips anything already present.

Installation states

Queued → Downloading → Verifying → Installing → Installed, with retry, cancel, failed, and skipped.

Windows & Office tools

Select a Windows build or Office release and prepare online or offline deployment.

IDM integration

When Internet Download Manager is detected, supported large downloads are handed off to IDM.

Troubleshooting

Check the local log for the failing step, then retry the item or change the catalog source.
